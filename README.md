# Sports-Analysis-Dashboard
🏏 ⚽ 🥅 I recently built an interactive Sports Analysis Dashboard using power BI, where I transformed raw Sports data into meaningful insights.

# What's insights the Dashboard?


•	Total_Match, Total_Points, Average_Points, Player_most Point show in cards, using DAX and Monthly trend by Total_Points scored.

•	Using filter Top 3 Points/Goals minute Played by Player name, Top 5 Total_Points by Player name.

•	Built KPI Section with important matrices like Average_Points and Total_Match by Points/Goals.

•	Win/Loss/Draw match ratio by team Player distribution by country.

•	Tools Used: Power BI, DAX, Data Modelling.

# Tools & Technologies
. Power BI Desktop

. Power Query

. DAX

. Excel/CSV/SQL Data Sources
